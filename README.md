## 🇬🇧 English

Image To TXT is an experimental set of Python desktop utilities for representing image/file data as text and converting it back. The image tool uses Base64 encoding and includes a Tkinter interface with image selection and preview.

### ✨ Repository contents
- `obraz do txt.py` — image-to-text / text-to-image utility
- `plik do txt.py` — file-oriented text conversion utility
- `requirements.txt` — Python dependencies

### 🚀 Installation

```bash
git clone https://github.com/Swir/Image-to-txt.git
cd Image-to-txt
pip install -r requirements.txt
python "obraz do txt.py"
```

## 🇵🇱 Polski

Image To TXT to eksperymentalny zestaw desktopowych narzędzi Python pozwalających reprezentować dane obrazu/pliku jako tekst oraz wykonywać konwersję odwrotną. Narzędzie obrazowe wykorzystuje Base64 i posiada interfejs Tkinter z wyborem oraz podglądem obrazu.

### ✨ Zawartość repozytorium
- `obraz do txt.py` — konwersja obraz ↔ tekst
- `plik do txt.py` — narzędzie konwersji danych plikowych
- `requirements.txt` — zależności Python

### 🚀 Instalacja

```bash
pip install -r requirements.txt
python "obraz do txt.py"
```

> Base64 is an encoding format, not encryption. / Base64 jest formatem kodowania, a nie szyfrowaniem.
